# @orqenix-pro/cli

Orqenix Pro command-line interface foundation.

Part 11A of Phase 6 — Pro CLI Foundation (gate G44-pro).

- Pro license token auth at startup
- Three output formatters: `--json`, `--table`, `--plain`
- Exit code table (0/1/2/3/4/5) with typed `CliError` taxonomy
- Command framework based on `node:util.parseArgs`
